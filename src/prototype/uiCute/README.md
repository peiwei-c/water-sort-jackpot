# AquaSort Cute UI — throwaway prototype

**Question:** What should a cute, engaging AquaSort personality look like (home + play + jackpot)?

## Run

```bash
npm run prototype:uiCute
```

Open http://localhost:3457 — flip variants with the bottom bar or `?variant=A|B|C`. Home / Play / Prize via the flow bar. Tap vials on Play to pour (tiny in-memory puzzle).

| Key | Name | Structure |
|-----|------|-----------|
| A | Soft Lab | Greenhouse path + chubby flasks + prize centrifuge sheet |
| B | Juice Bar | Continue-hero cafe + boba cups + gumball parlor |
| C | Creature Reef | Tide-pool map + fishbowl homes + clam lottery |

Not for production. Pick a direction (or steal bits), then fold into real Expo screens.
