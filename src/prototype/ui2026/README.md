# AquaSort UI 2026 — throwaway prototype

**Question:** What should the 2026 first-run feel like (loading → home → rules for new users)?

## Run

```bash
npm run prototype:ui2026
```

Open http://localhost:3456 — flip variants with the bottom bar or `?variant=A|B|C`.

| Key | Name | Structure |
|-----|------|-----------|
| A | Liquid Path | Path-as-home + story-card rules |
| B | Day Station | Continue-first light UI + sheet rules |
| C | Signal Editorial | Three equal pillars + sticky manual |

Not for production. Pick a direction, then fold the winner into real Expo screens.
